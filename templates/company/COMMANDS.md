# COMMANDS.md

Commands for {{COMPANY_NAME}}.

## Task Commands

/status
Show active tasks.

/recap
Summarize company progress.

/new-task
Create a new task.

/save-decision
Save durable decision.

/create-project
Create a new project folder.

/improve-skill
Improve a company skill.

## Routing

Tasks should be routed based on:
- Strategy → CEO / Strategy Lead
- Planning → Project Manager
- Execution → Specialist Agent
- Review → QA Agent
- Documentation → Technical Writer

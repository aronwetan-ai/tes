# QA Skill

Use this skill for:
- Testing
- Validation
- Bug reports
- Acceptance criteria
- Code review
- Output review

Rules:
1. Check correctness.
2. Check edge cases.
3. Check security risks.
4. Check usability.
5. Give actionable fixes.

Output format:
- Passed
- Issues
- Risks
- Fix recommendation

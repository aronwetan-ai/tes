# Coding Skill

Use this skill for:
- Code generation
- Debugging
- Refactoring
- API design
- Database schema
- Frontend/backend implementation
- Error analysis

Rules:
1. Identify the root cause first.
2. Give the fix directly.
3. Provide complete code only when requested.
4. Avoid long theory.
5. Include test or verification step when useful.

Debug output:
- Problem
- Cause
- Fix
- Command/code
- Verification

Implementation output:
- Folder structure
- Code
- How to run
- Test

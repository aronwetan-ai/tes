# HEARTBEAT.md

Self-check loop for NexusAI.

Before working:
1. What is the user's goal?
2. Which role should handle it?
3. Which skill is needed?
4. Is memory needed?
5. Can the output be concise?

After complex work:
1. Did it solve the goal?
2. Is it actionable?
3. Is it safe?
4. Should anything be saved to memory?
5. Should a skill/template be improved?

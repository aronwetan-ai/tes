# Research Skill

Use this skill for:
- Factual verification
- Tool comparison
- Market research
- Competitive analysis
- External references
- Current information

Rules:
1. Verify current information when possible.
2. Prefer primary sources.
3. Separate fact from inference.
4. Do not guess when data is available.
5. Summarize findings compactly.

## Real-Time Crypto Research Rules

For crypto market research tasks:

- If asked for current Fear & Greed Index, BTC price, market sentiment, funding, dominance, or news, use available browser/search/API tools first.
- Do not immediately say "I don't have real-time access" if tools are available.
- If tools are unavailable, explain briefly and suggest the exact API/source.

Preferred crypto sources:
- Fear & Greed Index: https://api.alternative.me/fng/
- BTC price: CoinMarketCap, CoinGecko
- On-chain data: Glassnode, Santiment
- News: CryptoSlate, The Block, Cointelegraph

Output format for Fear & Greed research:
1. Current value (today)
2. Yesterday / last week comparison if available
3. 1-week sentiment outlook
4. Risk note

Important:
- Do not give guaranteed trading signals.
- Separate fact, interpretation, and scenario.
- Always note data source and timestamp.

Output format:
- Finding
- Evidence
- Analysis
- Recommendation

# DevOps Skill

Use this skill for:
- Docker
- Kubernetes
- Linux/WSL
- CI/CD
- Cloud deployment
- Nginx
- Cloudflare Tunnel
- Monitoring
- Infrastructure automation

Rules:
1. Prefer safe commands.
2. Explain destructive commands before use.
3. Use dry-run when possible.
4. Separate local, staging, and production.
5. Never expose secrets.

Output format:
- Goal
- Architecture
- Commands
- Config
- Verification
- Rollback

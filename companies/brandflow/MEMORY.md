## Memory Rules (Company-Scoped)

Tulis ke file ini saat:
- **[DECISION]** keputusan brand / marketing strategi BrandFlow.
- **[ARCH]** perubahan internal BrandFlow (role, skill, struktur).
- **[CAMPAIGN]** campaign launch / conclusion.
- **[TASK]** task BrandFlow yang sedang berjalan.
- **[DONE]** task BrandFlow yang selesai.
- **[INSIGHT]** insight tentang audience, voice, channel performance.

Jangan tulis di sini:
- Setiap draft caption / variasi (yang final-ready saja kalau perlu).
- Routine social media post content.
- Keputusan holding-wide → `MEMORY.md` atau `memory/global.md`.
- Basa-basi, klarifikasi ringan.

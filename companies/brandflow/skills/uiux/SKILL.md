# UI/UX Skill

Use this skill for:
- UI layout
- UX flow
- Design system
- Labels
- Navigation
- Forms
- App screens
- Component behavior

Rules:
1. Prioritize clarity.
2. Reduce user confusion.
3. Use familiar patterns.
4. Explain design decisions briefly.
5. Include component-level suggestions.

Output format:
- UX problem
- Recommended solution
- Label/copy suggestion
- Component behavior

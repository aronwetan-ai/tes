# Content Skill

Use this skill for:
- Social media posts
- Articles
- Captions
- Ads
- Brand voice
- WhatsApp status
- Campaign text
- Landing page copy

Rules:
1. Match the requested tone.
2. Keep it natural.
3. Avoid over-formal language unless requested.
4. Provide ready-to-copy output.
5. Give variants only when useful.

Output format:
- Final text first
- Optional variants
- Notes only if needed

## Why This File

Bitcoin's 4-year halving cycle is the dominant timeframe in crypto research. Understanding **where** in the cycle we sit determines almost every other research conclusion: which patterns to weight, which sentiment readings are concerning, what risk posture to take, which on-chain metrics matter.

This file is the **canonical reference** for cycle-phase identification. Used jointly with `cycle-indicators.md` (model detail) and `wyckoff-method.md` (structural detail).

## What "The Cycle" Actually Is

```
Bitcoin halving       block-reward cuts in half every ~210,000 blocks
                      ≈ every ~4 years
Mining supply         falls per halving; demand inelasticity creates supply shock
Consequence           predictable supply-side reduction;
                      demand response varies per cycle but pattern repeats
```

Halvings to date:

## The 5-Phase Cycle Model

```
PHASE 1 — ACCUMULATION              ~12-18 months
   Where: post-cycle bear bottom
   Sentiment: dead, "crypto is over"
   Action: smart money quietly accumulates; retail uninterested

PHASE 2 — PRE-HALVING MARKUP        ~6-9 months
   Where: anticipation builds
   Sentiment: cautious optimism
   Action: price slowly rises; smart money still accumulating

[HALVING EVENT]

PHASE 3 — POST-HALVING MARKUP       ~12-18 months
   Where: parabolic phase
   Sentiment: euphoria building
   Action: new retail enters; LTH starts distributing

PHASE 4 — DISTRIBUTION / TOP        ~3-6 months
   Where: cycle peak
   Sentiment: peak euphoria
   Action: smart money distributes to FOMO retail; Pi cycle fires

PHASE 5 — MARKDOWN / BEAR           ~12-18 months
   Where: collapse and consolidation
   Sentiment: capitulation
   Action: -80 to -90% drawdown; back to Phase 1
```

Total: ~4 years; each phase varies cycle-to-cycle.

## Phase Identification Checklist

For each phase, multiple indicators confirm:

### Phase 1 — Accumulation
- [ ] Mayer Multiple consistently <1
- [ ] MVRV-Z near zero or negative
- [ ] NUPL in capitulation/hope zone
- [ ] LTH supply rising (cohort accumulating)
- [ ] Price near or above 200W MA
- [ ] F&G frequently <30
- [ ] Crypto absent from mainstream news

### Phase 2 — Pre-Halving Markup
- [ ] Price rising slowly (not parabolic yet)
- [ ] Mayer Multiple 1.0-1.5
- [ ] MVRV-Z rising from negative
- [ ] LTH still net accumulating
- [ ] F&G in 40-65 range
- [ ] Some institutional accumulation visible (ETF inflows for cycle 4+)

### Phase 3 — Post-Halving Markup
- [ ] Price parabolic
- [ ] Mayer Multiple 1.5-2.4
- [ ] MVRV-Z 2-7
- [ ] LTH starting to distribute
- [ ] F&G frequently >70
- [ ] Mainstream attention rising
- [ ] New retail entering (KYC volume on exchanges rising)

### Phase 4 — Distribution / Top
- [ ] Price euphoric
- [ ] Mayer Multiple >2.4
- [ ] MVRV-Z >7
- [ ] NUPL in euphoria zone (>0.75)
- [ ] Pi cycle firing or fired recently
- [ ] LTH supply falling (active distribution)
- [ ] Funding rates persistently elevated
- [ ] Mainstream FOMO ("everyone is talking about crypto")

### Phase 5 — Markdown / Bear
- [ ] Price -50% or more from cycle high
- [ ] Mayer Multiple back below 1
- [ ] MVRV-Z falling toward zero or negative
- [ ] LTH supply rising again (re-accumulating cheap)
- [ ] F&G frequently <30
- [ ] Capitulation events (cascading liquidations)
- [ ] Mainstream "crypto is dead" articles return

## Inter-Cycle Variation

Each cycle differs:

| Aspect | Cycle 1 (2012) | Cycle 2 (2016) | Cycle 3 (2020) | Cycle 4 (2024-) |
|---|---|---|---|---|
| Pre-halving runup | Mild | Modest | Significant | Pre-anticipated heavily |
| Post-halving peak | Massive % gain | Massive % gain | 7x gain | TBD |
| Top date | Apr 2013 / Dec 2013 | Dec 2017 | Apr / Nov 2021 | TBD |
| Cycle low | Jan 2015 | Dec 2018 | Nov 2022 | TBD |
| Drawdown depth | -85% | -84% | -77% | TBD |
| Cycle structure | Single peak | Single peak | Double-peak | TBD |
| Macro context | Easy money | QE3 era | COVID + ZIRP | Post-tightening |
| ETF | None | None | None | Spot ETF approved Jan 2024 |

Senior reads acknowledge:
- Each cycle is structurally similar but not identical.
- Macro context shifts each cycle.
- Spot ETF (post-2024) is a structural change.
- Institutional adoption continuing to grow.

## Cycle Compression Hypothesis

**Observation**: Each cycle's % returns have decreased from the prior:
- Cycle 1: ~5,500x from cycle low to high
- Cycle 2: ~120x
- Cycle 3: ~22x
- Cycle 4: TBD (likely <22x if compression continues)

**Hypothesis (debated, not proven)**: As BTC market cap grows, % returns compress. Eventually, BTC may transition to lower-volatility "macro asset" behavior similar to gold.

**Operational implication**:
- Don't size positions based on prior cycle's % gains.
- Don't expect 100x returns on BTC; alts may still deliver but with higher risk.
- Phase timing may also compress.

## Cycle vs Macro — Which Wins?

When 4-year cycle frame and macro liquidity disagree:

```
Cycle suggests Phase 3 markup    +  Macro liquidity contracting
  → Cycle dampened, peak lower or delayed
  → Historical: 2018 cycle bottom delayed by macro QT

Cycle suggests Phase 5 bottom    +  Macro liquidity expanding
  → Bottom often arrives earlier than cycle math suggests
  → Historical: 2022 cycle bottom Nov 2022 with QE return ~Q4 2022
```

Senior pattern: cycle is **frame**, macro is **modulator**. Never trade one without the other.

## Cycle 5 (Post-2028 Halving) Open Questions

Honest admissions for future research:

- Will spot ETF adoption flatten the cycle?
- Will institutional dominance reduce volatility?
- Will macro regime align or work against next cycle?
- Will the 4-year pattern continue when BTC market cap exceeds gold?
- Will altcoin season patterns persist or fragment?

These are unknown. Senior research **flags them as unknown**, doesn't pretend to certainty.

## Anti-Patterns

- **Calendar predictions**: "Cycle top will be October 2025." N=3; calendar is weak basis.
- **Single-indicator phase calls**: "MVRV-Z says we're in Phase 4." Convergence required.
- **Ignoring macro**: Cycle math without liquidity overlay is half-blind.
- **Forgetting structural change**: ETF, regulation, institutional flows shift dynamics.
- **Stock-to-flow worship**: S2F broke post-2022. Don't promote past evidence.
- **Cycle compression denial**: Each cycle has compressed; ignoring this = oversized expectations.
- **Cycle compression certainty**: Compression is hypothesis; don't promise it either.

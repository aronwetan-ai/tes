---

## Prinsip Marketing Inti

1. **Audience first, brand second.**
   Mulai dari masalah audiens, bukan dari fitur produk.

2. **Specific beats generic.**
   "Untuk founder SaaS B2B yang baru raise seed" > "untuk semua orang".

3. **Show, don't tell.**
   Contoh konkret > klaim abstract.

4. **Hook earns the read.**
   Kalau hook tidak menarik, sisa konten tidak dibaca.

5. **Measure or it didn't happen.**
   Setiap campaign harus punya KPI sebelum publish.

## Workflow Standar Per Task

### Step 1 — Brief Lengkap

Sebelum mulai produksi, pastikan punya:
- **Audience**: siapa target spesifik (umur, peran, masalah)?
- **Goal**: awareness / engagement / conversion / retention?
- **Channel**: Instagram / LinkedIn / Twitter / blog / email?
- **Tone**: professional / casual / playful / authoritative?
- **Format**: caption / carousel / thread / artikel?
- **Constraint**: panjang, deadline, brand guideline?

Jika brief tidak lengkap, tanya. Jangan kerjakan asal.

### Step 2 — Strategy Sketch

Sebelum nulis copy, sketsa dulu:
- **Big idea** apa yang dibawa (1 kalimat)?
- **Hook** yang akan dipakai (3-5 opsi)?
- **CTA** yang diharapkan (apa yang user lakukan)?

### Step 3 — Produksi

- Mulai dari hook.
- Body singkat, padat, satu ide per paragraf.
- CTA jelas dan spesifik.
- Sediakan minimal 2 variasi tone (kecuali brief kunci 1 tone).

### Step 4 — Self-Review

Sebelum kirim:
- Apakah hook **menarik attention** dalam 3 detik?
- Apakah body **menjaga attention** sampai akhir?
- Apakah CTA **jelas** apa yang harus dilakukan?
- Apakah **tone** match dengan brand & channel?
- Apakah ada **typo** atau grammatical error?

### Step 5 — Tag dengan Metadata

Setiap output marketing wajib disertai metadata di bagian bawah:
```
[META]
Audience    : <siapa>
Channel     : <dimana>
Goal        : <kenapa>
Tone        : <bagaimana>
KPI         : <apa yang diukur>
```

## Framework Copywriting

### AIDA — Untuk Sales Copy
- **A**ttention: Hook yang berhenti scroll.
- **I**nterest: Detail yang relevan dengan audiens.
- **D**esire: Manfaat yang membuat ingin punya.
- **A**ction: CTA jelas.

### PAS — Untuk Problem-Solving Content
- **P**roblem: Masalah audiens yang nyata.
- **A**gitate: Buat masalah terasa penting / urgent.
- **S**olve: Solusi yang ditawarkan.

### BAB — Untuk Transformation Story
- **B**efore: Kondisi sebelum.
- **A**fter: Kondisi sesudah.
- **B**ridge: Apa yang menjembatani.

## Hook Patterns

Pilih hook berdasarkan tujuan:

| Tujuan          | Pattern                                              |
|-----------------|------------------------------------------------------|
| Curiosity       | "Saya kira X, ternyata Y."                           |
| Contrarian      | "Semua orang bilang X. Itu salah."                   |
| Specific Number | "5 hal yang saya pelajari dari 100 launch."          |
| Pain Point      | "Pernah X? Kamu tidak sendirian."                    |
| Bold Claim      | "Cara tercepat untuk X adalah Y."                    |
| Question        | "Kenapa X selalu Y? Ternyata jawabannya..."          |
| Story           | "Tahun lalu saya gagal X. Inilah yang saya pelajari."|

Hindari hook clickbait yang tidak ditepati di body.

## Standar Per Channel

### Instagram
- Caption max 150 kata untuk feed post.
- 5-10 hashtag relevan, bukan 30 random.
- Selalu ada CTA di akhir.
- Variasi tone: casual + visual-friendly.

### LinkedIn
- Hook 1-2 baris pertama.
- Line break setiap 1-2 kalimat (mobile-friendly).
- Akhiri dengan pertanyaan untuk engagement.
- Tone: professional tapi personal.

### Twitter / X
- Thread: hook tweet harus stand-alone menarik.
- Setiap tweet thread harus self-contained.
- CTA bisa di tweet terakhir.
- Tone: punchy, padat, opinion-driven.

### Blog / Artikel
- Title: spesifik + benefit.
- Intro: 100-150 kata, frame masalahnya.
- Body: H2/H3 untuk navigasi, bullet point untuk skim.
- CTA: minimal di akhir, opsional di tengah.
- Tone: educational, authoritative.

### Email
- Subject line: < 50 karakter, curiosity / benefit.
- Body: 100-300 kata maksimal.
- Satu CTA utama, bukan banyak link.
- Tone: personal, seperti menulis ke satu orang.

```

Format   : <caption / carousel / thread / etc>
Topic    : <topik utama>
Hook     : <hook yang dipakai>

```

Aturan distribusi:
- 60% educational / value-giving
- 30% engagement / community
- 10% promotional / sales

## SEO Checklist

Setiap artikel blog:
- [ ] Target keyword jelas (1 primary + 2-3 secondary).
- [ ] Title mengandung primary keyword + benefit.
- [ ] Meta description 150-160 karakter, ada CTA.
- [ ] H1 = title, H2/H3 menyertakan secondary keyword natural.
- [ ] Panjang artikel sebanding dengan top-3 SERP competitor.
- [ ] Internal link minimal 2 ke artikel relevan.
- [ ] External link ke source terpercaya jika klaim fakta.
- [ ] Image alt text deskriptif (bukan "image1.png").
- [ ] URL slug pendek, lowercase, hyphen.

## Hal yang TIDAK Boleh Dilakukan

- **Generic copy** yang bisa dipasang di brand mana pun.
- **Klaim hiperbolik** tanpa data ("the best in the world", "100% guaranteed").
- **Plagiat** dari competitor — inspirasi boleh, copy tidak.
- **Skip metadata** karena buru-buru.
- **Publish tanpa KPI** — kalau tidak ada KPI, tidak tahu sukses atau tidak.
- **Push semua channel sama persis** — adapt untuk setiap channel.

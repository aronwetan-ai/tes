# Copywriting Frameworks Cheatsheet

Versi: 1.0 (Update 11)
Last updated: 2026-05-17
Audience: BrandFlow agents — `@brandflow.copywriter`, `@brandflow.cmo`, `@brandflow.writer`

---

## Why Frameworks

A copywriting framework is a structural skeleton — it tells you the *order* of moves, not the words. Picking the right framework before drafting saves 80% of revision time downstream.

Senior copywriters don't worship frameworks. They pick the one that fits the **piece's job + audience + format**, then break the framework where breaking it makes the piece better. The framework is scaffolding, not law.

---

## Picker — One-Line Decision

| Piece's job | Default framework |
|---|---|
| Sales / direct response | **AIDA** or **PAS** |
| Problem-led education | **PAS** |
| Transformation story | **BAB** |
| Brand story / narrative arc | **StoryBrand** |
| Product feature explanation | **FAB** |
| High-stakes ad / campaign | **4U** |
| Long-form thought leadership | **Problem-Promise-Proof** |
| Welcome / onboarding email | **WIIFM** |
| Crisis / correction post | **AAA** (Acknowledge / Action / Ask) |

## AIDA — Attention, Interest, Desire, Action

**Use for:** sales copy, ad copy, landing pages, sales emails.

```
A — ATTENTION    Hook stops the scroll / earns the click.
I — INTEREST     Detail relevant to the audience's specific situation.
D — DESIRE       The promise / outcome they want, made vivid + believable.
A — ACTION       Single clear CTA.
```

Example (cold email opening):
```
A: "Cold email kamu balik 3% — itu standar industri."
I: "Tapi kalau kamu founder B2B yang send 50 email/minggu, 3% = 1-2 reply.
    Itu bukan deal flow."
D: "Cara naikin reply ke 12-18% bukan ubah copy. Ubah timing kirim
    + ubah subject pattern."
A: "Reply 'YES' kalau mau breakdown 6-langkah-nya — gratis."
```

Anti-pattern: starting with "I" (Interest) before "A" (Attention). Reader never gets to your interest because they didn't read past the hook.

## PAS — Problem, Agitate, Solve

**Use for:** problem-solving content, awareness ads, painful-truth posts.

```
P — PROBLEM     The audience's pain stated in their words.
A — AGITATE     Dimensions of cost: time, money, status, identity.
S — SOLVE       The path / product / approach that addresses it.
```

Example (LinkedIn post):
```
P: "Posting 5×/minggu, engagement masih flat."
A: "Algoritma 2026 baca SAVE, bukan LIKE. Konten tanpa save-bait
    tidak compound. Tiap post yang lewat tanpa save = follower yang
    lewat tanpa balik. Setelah 3 bulan, dashboard penuh angka stagnan."
S: "Setiap post wajib punya 1 dari 3 save-trigger: framework yang bisa
    di-reference, list yang bisa di-screenshot, atau hook 'simpan ini buat...'."
```

Calibration: "Agitate" doesn't mean "be melodramatic." It means making the existing pain visible. If audience already feels the pain, ONE line agitate is enough; over-agitating reads as manipulation.

## BAB — Before, After, Bridge

**Use for:** transformation stories, case studies, before/after social posts.

```
B — BEFORE      The state the audience is in now (or was in).
A — AFTER       The state after the transformation.
B — BRIDGE      What got them from before to after — the mechanism.
```

Example (case study post):
```
B: "Engagement client A: 0.8% (Jan)."
A: "4.2% (Apr). Same audience, same posting cadence."
B: "Yang berubah: konten mix bergeser dari 80% promo → 60% educational.
    Save rate naik 5×. Reach naik tanpa beli."
```

Common failure: skipping the "Before" because the writer assumes context. Without Before, the After lands flat. Always anchor.

## 4U — Useful, Urgent, Unique, Ultra-Specific

**Use for:** headlines, subject lines, ad copy, anywhere a single line carries weight.

```
USEFUL          Does it offer real value to a specific audience?
URGENT          Why should they care now, not later?
UNIQUE          What's different about this take/offer?
ULTRA-SPECIFIC  How concrete and specific is it?
```

Score a candidate headline 1-5 on each dimension. Total < 12 = weak; 12-15 = decent; 16+ = sharp.

Example:
```
"5 ways to grow on LinkedIn" → 1+1+1+2 = 5 (weak)
"How a B2B founder grew LinkedIn from 2k to 27k in 90 days using 1 carousel format" → 5+4+4+5 = 18 (sharp)
```

## FAB — Features, Advantages, Benefits

**Use for:** product pages, feature explanations, sales enablement.

```
F — FEATURE     What the thing IS.
A — ADVANTAGE   What that feature DOES.
B — BENEFIT     What that means for the customer's life.
```

Customers buy benefits. Junior copy stops at features ("12-megapixel sensor"). Senior copy walks down to benefit ("photos sharp enough to print at 24×36 — your kid's first birthday on the wall, not stuck in a phone").

Always finish at B. If you can't articulate B, the feature shouldn't be in the copy.

## StoryBrand (B.J. Miller / Donald Miller — paraphrased for compliance)

**Use for:** brand-narrative pieces, hero pages, brand story emails.

```
1. CHARACTER       The customer is the hero (NOT the brand).
2. PROBLEM         Hero faces an external + internal + philosophical problem.
3. GUIDE           The brand is the GUIDE (not the hero).
4. PLAN            The brand provides a clear plan to solve the problem.
5. CALL TO ACTION  Clear direct CTA + transitional CTA (e.g., download).
6. AVOIDS FAILURE  What's at stake if the customer doesn't act.
7. ACHIEVES SUCCESS  The transformed end-state.
```

Core inversion: the brand isn't the hero of the story. The customer is. The brand is Yoda, not Luke. Most brand copy fails this — it makes the brand the hero.

## Problem-Promise-Proof (P3)

**Use for:** long-form thought leadership, SEO articles, conversion-leaning blog posts.

```
PROBLEM     The pain framed as the audience experiences it.
PROMISE     The specific outcome this article will deliver.
PROOF       Evidence (data, case, demonstration) that the promise can be kept.
```

Lives at the intro. Body delivers on it. Conclusion synthesizes + CTAs.

Example (intro):
```
Problem:  "Kebanyakan founder Indonesia gagal scale konten LinkedIn beyond 2k.
          Bukan karena kualitas. Karena pattern format yang salah dipakai."

Promise:  "Artikel ini ngebreakdown 1 carousel format yang konsisten 5-15× lipat
          jangkauan biasanya — bukan teori, dipakai 12 founder klien kami."

Proof:    "Sample size: 47 carousel published Q1 2026. Avg jangkauan vs feed
          post lain di akun yang sama: 8.4×. Data screenshot di section terakhir."
```

## WIIFM — What's In It For Me

**Use for:** welcome emails, onboarding flows, any first-touch where you're not yet trusted.

Not really a structural framework — it's a question to ask of every paragraph: "If a stranger reads this paragraph, what's in it for *them*?"

Apply ruthlessly. Cut paragraphs that fail the test.

---

## AAA — Acknowledge, Action, Ask

**Use for:** crisis correction, post-mistake communication, accountability moments.

```
ACKNOWLEDGE   The specific thing that went wrong, in concrete terms.
ACTION        What we did to address it (already done, not "we will").
ASK           What we ask of the audience — patience, feedback, etc.
```

See `companies/brandflow/skills/community/crisis-playbook.md` for full crisis structure.

## "Slippery Slide" Principle

(Joseph Sugarman — paraphrased for compliance.)

The single job of every sentence is to **make the reader read the next sentence**. The first line earns the second. The second earns the third.

Test: cover any one sentence. Does the rest still flow? If yes, that sentence might be cuttable. The "slide" should feel inevitable.

This isn't a framework — it's a discipline that works *with* every framework above.

## Framework Anti-Patterns

- **Forcing AIDA on a story-driven brand piece.** AIDA is for response copy; brand stories use BAB or StoryBrand.
- **PAS without empathy.** Agitating pain you don't actually understand reads as manipulative.
- **BAB without specific Before.** "Before, things were tough" — meaningless. Specific or cut.
- **FAB stopping at A.** Always reach B. The customer pays for B, not F or A.
- **AIDA → AIDA → AIDA across every piece.** Audience tires of the same skeleton. Vary.
- **4U applied dogmatically.** Sometimes "useful + ultra-specific" is enough; not every line needs urgency.
- **Stacking 3 frameworks in one piece.** Pick one. Pure execution beats mixed gestures.

---

## Layering Frameworks at Different Levels

It's fine to use **one framework at the piece level** and **a different framework at the section level**. Common pattern:

```
PIECE LEVEL:    StoryBrand (overall narrative arc).
INTRO:          P3 (Problem, Promise, Proof).
EACH SECTION:   FAB or BAB inside.
CTA:            AIDA's "A" (single, clear, specific).
```

Junior copy uses one framework everywhere. Senior copy nests appropriately.

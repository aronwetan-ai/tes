### Gaps Identified
1. **❌ No client voice file exists** — `companies/brandflow/clients/crypto-influencer/voice.md` doesn't exist. Had to improvise. In production, copywriter MUST escalate to @brandflow.ceo before drafting without voice profile.
2. **❌ No cross-company review protocol** — Who reviews the BrandFlow draft for factual accuracy? The handoff says "@crypto.qa reviews factual accuracy before publish" but there's no formal routing mechanism (task logger entry? inbox message? DM?).
3. **⚠️ Disclaimer format inconsistency** — Crypto Consultant's disclaimer is bilingual (ID + EN). BrandFlow's marketing version is EN-only. No standard for which to use when.
4. **⚠️ Expiry discipline unclear** — Content has decay (May 31) aligned with Forecast Ledger, but there's no mechanism to auto-remove/archive expired content. Manual tracking only.
5. **⚠️ Approval flow undefined** — "Needs Fathur approval" is stated but HOW does that happen? Task logger? Telegram message? There's no defined workflow step.
6. **⚠️ No @brandflow.analytics pre-set KPIs** — KPIs stated (saves, shares) but no baseline or target number. Analytics can't evaluate without a target.
7. **⚠️ No hashtag set defined** — IG carousel has no hashtags. Social media agent should define 5-10 relevant hashtags per channel norms.
